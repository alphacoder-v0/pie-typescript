## Adjudications requested by the orchestrator

- **9 SILENCE markers confirmed** in A (lines 49, 59, 73, 82, 95, 182, 355, 472, 505; grep hits at 218/293 are cross-references). They encode 8 distinct unanswered questions (ValueError appears twice). All 8 verified as genuine rulebook/inventory silences.
- **B's `_dump_str` claim verified true and understated**: the original doesn't just produce malformed TOML (`'a\x01b'` → `"ax01b"`, escape backslash dropped) — it **crashes** with IndexError on strings *starting* with a control character (`'\x01'`, `'\x1b[31m'`, `'\x00'`, `'\x7f'` all verified). **Ruling: reproduce exactly, don't adopt the correction** (rows 1–2): the final parity gate compares against the original, and a "corrected" port turns every control-char scenario into noise that masks real translation errors. The correction is right on the merits and belongs in a flagged post-parity patch. Note A failed exact reproduction anyway: it neither corrupts identically nor crashes — it emits `"01xundefined"` (row 2, both wrong).
- **Unreachable code removal**: split ruling — the `u`-prefix strip is genuinely dead and its removal is harmless (row 9, both defensible against a too-blunt S0); the `TomlArraySeparatorEncoder` flatten loop is a live subclass extension point and its removal forecloses behavior Python permits (row 10, rulebook right).
- **Dispatch table restructure**: rulebook right (row 8) — the restructure forced B to delete `TomlNumpyEncoder` and weaken `TomlPreserveCommentEncoder` to duck typing, demonstrating the table is structural, not stylistic.

## Score

14 material differences: **rulebook right 9 · native right 2 · both defensible 2 · both wrong 1.**
The rulebook's wins are real (rows 5, 7, 10 are decisive, evidence-backed) but four of the nine
rest on S0 posture rather than a specific written rule, and both native-right rows plus the
both-wrong row land on questions the rulebook never answered. The rulebook's weakness is not
wrong rules — it is silence: 8 distinct SILENCEs, of which two (float formatting, index
semantics) let observable parity defects into A.

## AMENDMENT QUEUE

1. **(rows 1, 3)** Add to S0: when the source's behavior is itself defective (malformed output or crash), reproduce it bug-for-bug and mark the site `BUG(port): <repro>` — a third greppable marker alongside TODO/PERF. Parity scenarios assert the defective output; fixes ship only in a flagged post-parity patch. (B's author had to guess this policy; A reproduced bugs with no machine-findable record that they are bugs.)
2. **(row 2)** Add to S2: Python sequence indexing raises IndexError out of bounds; JS returns `undefined`. Any translated index/`.at()` access whose Python counterpart can raise must either replicate the throw (explicit bounds check) or carry a marker. A shipped `"01xundefined"` — silent `undefined` concatenation — under the current rules with zero flags.
3. **(row 4)** Add to S2 a float-formatting row: `str(float)` ≠ `String(number)`. Mandate `nan`/`inf`/`-inf` for non-finite values (matches Python and TOML exactly — closed-form, no TODO permitted), and enumerate the residual exponent-form divergences (`1e-05` vs `0.00001`) as accepted-with-marker.
4. **(rows 5, 6)** Extend the S2 int/float row: codify `Number.isInteger` (not `isSafeInteger`) as the int/float dispatch, and declare the known accepted losses — integral floats render without `.0` — so the parity harness normalizes them instead of each translator rediscovering the problem.
5. **(row 8)** Add to S2: Python type-keyed dispatch dicts (`{type: fn}`) map to `Map<string|Function, fn>` keyed by `_py_type` tags (`'str' | 'bool' | 'int' | 'float' | 'list'`) plus constructor references for classes; `_py_type` becomes a shared spec'd helper. Subclass contracts that mutate the table (numpy, CommentValue) depend on this.
6. **(row 11)** Replace the inventory's exclusion-list phrasing for `isTable` with a positive definition: `Object.getPrototypeOf(v) === Object.prototype || proto === null` — the faithful image of `isinstance(x, dict)`. Assign it a home module (A's SILENCE #2: semantics were specified, location was not).
7. **(row 12)** Extend the None→null row: `null` reaching `dump_value`/`dump_inline_table` renders `"null"` where Python renders `"None"` — declare accepted and parity-normalized; null entries inside inline tables must be emitted, never skipped.
8. **(row 13)** Add an exceptions row to S2: encoder-side `ValueError`/`TypeError` map to `Error`/`TypeError` with byte-identical messages; messages are part of the parity surface. (A improvised this twice — SILENCE #6/#8 — and happened to match B only by luck.)
9. **(rows 8, 14 + SILENCEs #1, #9)** Add a no-analog-types scope row: Decimal, numpy scalars, pathlib each get an explicit disposition (drop with shim class preserved, or typed extension point). Three of A's nine SILENCEs are this one missing row.
10. **(row 1)** Canonize A's `_repr` as a shared, test-vectored helper (the `%r` emulation): quote-selection rules + escape table, with the verified control-char vectors from this report as its fixture set, so fan-out files do not re-derive CPython repr semantics independently.
